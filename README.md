# Weekly Data Analysis Challenge

A collection of weekly data analysis exercises completed in Jupyter Notebooks. Each challenge is an opportunity to practice exploring datasets, cleaning and transforming data, identifying patterns, and communicating insights with clear visualizations.

## Goals

- Build consistent data analysis habits through weekly practice
- Strengthen Python and Jupyter Notebook skills
- Practice data cleaning, exploration, visualization, and interpretation
- Document analytical thinking and communicate findings clearly

## Repository contents

The main content of this repository is organized as Jupyter Notebooks. Each notebook focuses on a weekly challenge and may include:

- Problem definition and analysis questions
- Data preparation and cleaning
- Exploratory data analysis
- Charts and visualizations
- Findings, observations, and conclusions

## Getting started

### Requirements

- Python 3.9 or later
- Jupyter Notebook or JupyterLab
- Common data-analysis libraries such as `pandas`, `numpy`, and `matplotlib`

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Krishma-adhikari/weekly-challenge-data-analysis.git
   cd weekly-challenge-data-analysis
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

   On Windows PowerShell, use:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

3. Install the packages required by the notebooks. For example:

   ```bash
   pip install jupyter pandas numpy matplotlib seaborn
   ```

4. Start Jupyter:

   ```bash
   jupyter notebook
   ```

5. Open a notebook and run the cells from top to bottom.

## Suggested workflow

1. Read the challenge and define the questions to answer.
2. Inspect the data and check its quality.
3. Clean and transform the data as needed.
4. Explore patterns using summary statistics and visualizations.
5. Record the key findings and limitations.
6. Review the notebook so that the analysis is reproducible and easy to follow.

## Tools

- **Python** for analysis
- **Jupyter Notebook** for interactive work
- **pandas** and **NumPy** for data manipulation
- **Matplotlib** and **Seaborn** for visualization
